ClipDock 0.3.0 — installation

Requires macOS 14 or later. Supports Apple Silicon and Intel.

1. Drag ClipDock.app onto Applications to install into /Applications.
2. Wait for the copy to finish, then eject the ClipDock disk image.
3. Launch ClipDock from Applications. Its icon appears in the menu bar.

To update, quit ClipDock first and confirm replacement in Applications.
History and settings are preserved. Only run one copy at a time.

This is an experimental, ad-hoc-signed build without Developer ID or Apple
notarization. If macOS blocks it, only approve it if you trust the source:
System Settings > Privacy & Security > Open Anyway, after attempting launch.
Do not disable Gatekeeper. Managed Macs may prohibit running this build.
Apple instructions: https://support.apple.com/102445

Automatic paste requires Accessibility permission granted by you.
Without that permission, copy an item and paste manually with Command-V.

GameMode.command delegates to the installed ClipDock app. Function keys must be
changed and restored manually in Keyboard settings. Physical keyboard behavior
and complete Game Mode cycling are UNVERIFIED_MANUAL. LinearMouse is not bundled.

Source, known limitations and verification status:
https://github.com/TESA1DE/ClipDock
