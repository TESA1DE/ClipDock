# Changelog

## 0.3.0 — release candidate

- Add graphical local action editing, persistence, per-action global shortcuts,
  app launch/quit, confirmed Bash execution, and paired ON/OFF scripts.
- Add assisted Game Mode with manual keyboard confirmation and LinearMouse ownership.
- Add GameMode.command delegating to the installed app.
- Separate global hotkey event IDs; reject unrelated events.
- Preserve corrupt action files and report shortcut/storage errors.
- Add action persistence and script validation tests, installation/uninstallation docs.
- Automatic function-key switching is not implemented; manual validation remains open.

## 0.2.0

- Clipboard history, drag and paste, quick app launcher, configurable appearance.
- Retention, compact age labels, settings titlebar background, universal DMG packaging.
